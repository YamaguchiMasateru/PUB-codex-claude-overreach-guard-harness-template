# 並行作業の手順

Codex と Claude Code など、複数の親セッションが同じリポジトリで作業するときの調整方法です。親が担当範囲を割り当てる手順（[運用規約](../conventions.md)）は、1 つの親セッションの内側を調整するもので、別の親セッションが同時に同じファイルを変更する場合は調整できません。このため、次のいずれかで作業を分けます。自動のロックは設けません。

## 同じ worktree で共同作業する場合

- 統合担当の親を 1 人決めます。共有ファイル（Skill、`.repository-docs/`、`AGENTS.md`、共有経験知の本文と索引）への書込みは、統合担当が調整します。
- 他の親は担当範囲を統合担当に伝え、範囲外のファイルを編集しません。共有経験知の候補は本文と根拠を統合担当へ報告し、採否と保存は [経験知の運用手順](repository-knowledge.md) に従って統合担当が行います。
- 作業の開始時に、他の親が編集中のファイルがないか確認します。

## 独立して並行作業する場合

- 親ごとに worktree と branch を分けます。
- 統合時に両方の差分を比較し、共通ファイル、設定、共有経験知の重複・矛盾・古い参照を統合してから取り込みます。
- 実行時ステート（`.repository-state/` 配下の Git 管理外ファイル）は worktree ごとに分かれるため、他の worktree の履歴は参照できません。

## 共通の注意

- 実行環境ごとの設定（`.codex/`、`.claude/`）は、その環境の担当だけが変更します。共通ファイルを変更するときは、もう一方の環境への影響を確認します。
- 変更後は `harness.py validate` を全環境で実行し、問題がないことを確認してから引き継ぎます。
