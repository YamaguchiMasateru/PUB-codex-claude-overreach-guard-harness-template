# リポジトリ経験知の保存方針

リポジトリ作業で観測・検証した成功、失敗、制約から、次の判断や行動を変える再利用可能な知見を共有する。経験した担当者が条件と根拠を含む本文を作り、委譲元が採否・既存項目との統合・保存先・最終確認を担う。実行手順の正本は [repository-memory Skill](../../.agents/skills/repository-memory/SKILL.md) に置く。

経験知の正本は [.repository-state/memory/](../../.repository-state/memory/index.md) に置く。成功と失敗を同じテーマで扱い、条件・限界・確認日を残す。必須規約と確定した設計は `.repository-docs/` に置く。個人の好みや端末固有の情報、生ログは共有記録に含めない。
