# `implement` 呼び出し指示

担当者は作業前に `.agents/skills/delegate-implement/SKILL.md` と `.agents/skills/repository-memory/SKILL.md` を読む。子は委譲元向けの起動・評価を実行せず、自身の役割方針と報告を適用する。
委譲元エージェントは以下の5項目を今回の変更に合わせて記入し、起動時に渡す。担当者が単独で依頼を理解できる量のコンテキストを選ぶ。参照できる資料はパスと該当箇所を示し、参照できない情報は必要部分を本文に含める。会話履歴の継承だけに依存しない。情報が足りなければ担当者は不足点を委譲元エージェントに報告する。担当ファイルの所有を明確にし、並行作業者の変更を戻さない。

```markdown
## 期待するゴール
- 知見報告（本文付き候補・既存対応済み・該当なし）も提出する。
- 実現する動作と提出する差分・報告：
## 許可する作業
- メモリー保存先の所有権（なければ保存不可）と索引・要約の所有者：
- 所有するファイル・機能、編集・確認できる操作：
## 実行してはいけない作業
- 担当外の編集、追加委譲、許可されていない外部書込み：
## 必要なコンテキスト
- 関連既存知見、[repository-memory](../../repository-memory/SKILL.md) の参照、記録可否と明示保存先：
- 依頼の背景、確認済みの事実、参照資料のパスと該当箇所、設計・制約、実施済み確認と結果：
## 完了条件
- 候補なら完成本文と根拠を報告し、保存を担当した場合は本文・索引・要約の差分で確認する。採否の最終判断は委譲元が行う：
- 条件ごとに、委譲元エージェントが確認する差分・確認結果と合否の判定方法：
- 残件・未確認事項の報告：
```

## 記入例：CLI の入力検証を修正（仮想案件）

```markdown
## 期待するゴール
- 知見報告（本文付き候補・既存対応済み・該当なし）も提出する。
- CLI の `--output` に空文字を渡した際、処理前に入力エラーとして終了する変更を提出する。
## 許可する作業
- メモリー保存は担当外。候補本文と根拠のみ報告する。
- `scripts/example_cli.py` の引数処理と `tests/test_example_cli.py` を所有・編集し、対応テストを実行する。
## 実行してはいけない作業
- 他機能や設定の編集、追加委譲、外部サービスへの書込み。並行作業者の変更を戻さない。
## 必要なコンテキスト
- 関連既存知見は未設定。メモリー保存先は未指定。
- 現状は空文字が後段に渡る。引数処理は `scripts/example_cli.py` の `parse_args`、対象テストは `tests/test_example_cli.py` の `test_empty_output`。委譲元エージェントが変更対象の実在を確認して渡す。出力形式は同ファイルの既存入力エラーに合わせる。委譲元エージェントが実行済みの `uv run pytest tests/test_example_cli.py` は `test_empty_output` だけ失敗しており、成功済みテストは重複実行しない。
## 完了条件
- 知見候補があれば完成本文と根拠を報告し、委譲元が採否を判断できる。
- 委譲元エージェントが差分で空文字の拒否と既存エラー形式との整合を確認できる。
- 対応テストのコマンドと成否を報告し、委譲元エージェントがテスト結果またはログを確認できる。変更ファイルと残件も報告する。
```

上のパス・関数名は記入例であり、起動前に今回の実在する対象へ置き換える。委譲元エージェントは各条件の証拠を確認して判定し、一般的な未確認範囲と必須条件の未達を区別する。
