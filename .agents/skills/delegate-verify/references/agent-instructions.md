# `verify` 呼び出し指示

担当者は作業前に `.agents/skills/delegate-verify/SKILL.md` と `.agents/skills/repository-memory/SKILL.md` を読む。子は委譲元向けの起動・評価を実行せず、自身の役割方針と報告を適用する。
委譲元エージェントは以下の5項目を今回の検証に合わせて記入し、起動時に渡す。担当者が単独で確認対象を理解できる量のコンテキストを選ぶ。参照できる資料はパスと該当箇所を示し、参照できない情報は必要部分を本文に含める。会話履歴の継承だけに依存しない。情報が足りなければ担当者は不足点を委譲元エージェントに報告する。成功済み確認は対象・コマンド・結果を渡し、再実行を完了条件にせず、委譲元エージェントが既存証拠を確認する。

```markdown
## 期待するゴール
- 知見報告（本文付き候補・既存対応済み・該当なし）も提出する。
- 確認対象と報告する結果：
## 許可する作業
- メモリーは保存不可。Git管理外ログの保存先：
- 読取り対象、実行する局所チェック、Git 管理外ログの保存先：
## 実行してはいけない作業
- Git 管理対象の編集、追加委譲、許可されていない外部書込み・サービス接続：
## 必要なコンテキスト
- 関連既存知見、[repository-memory](../../repository-memory/SKILL.md) の参照、記録可否と明示保存先：
- 変更意図、対象差分、参照資料のパスと該当箇所、制約、成功済み確認の対象・結果：
## 完了条件
- 候補なら完成本文と根拠を報告する。採否・保存先の最終判断は委譲元が行う：
- 条件ごとに、委譲元エージェントが確認するチェック結果・ログと合否の判定方法：
- 未実施・失敗・未確認範囲の報告：
```

## 記入例：スキル変更を確認（仮想案件）

```markdown
## 期待するゴール
- 知見報告（本文付き候補・既存対応済み・該当なし）も提出する。
- `delegate-implement` の Skill 変更が依頼意図と既存規約に整合するか報告する。
## 許可する作業
- メモリーは保存不可。ログは指定のGit管理外領域へ保存する。
- `.agents/skills/delegate-implement/SKILL.md` と `references/agent-instructions.md`、その差分を読み、スキル用 validator を実行する。ログ保存は Git 管理外の指定先だけにする。
## 実行してはいけない作業
- Git 管理対象の編集、追加委譲、外部サービスへの接続・書込み。成功済みチェックの再実行。
## 必要なコンテキスト
- 関連既存知見は未設定。メモリーは保存不可。
- 変更意図は起動指示に必要な5項目と委譲元エージェントによる完了判定を追加すること。対象差分は上記2ファイル。既存規約は `AGENTS.md` の「変更記録・確認」と `.agents/skills/delegate-implement/SKILL.md` の担当・制限。委譲元エージェントは利用可能な skill-creator の `scripts/quick_validate.py` の場所を確認し、その環境で解決したパスと対象 Skill を指定するコマンドを渡す。`git diff --check` は対象差分について成功済みで、その結果も渡す。
## 完了条件
- 候補があれば完成本文と根拠を報告し、委譲元が採否を判断できる。
- 委譲元エージェントが報告された対象と差分を照合し、変更意図・規約との矛盾、重複、古い参照の有無を判定できる。
- 委譲元エージェントが確認したスキル用バリデーターで対象を検証し、実行コマンド・成否・Git 管理外ログの場所を報告する。委譲元エージェントが結果を確認でき、実行済みの `git diff --check` は渡された証拠を確認した旨を示す。
- 未実施・失敗・未確認範囲を区別して報告する。
```

上の対象位置とチェックは記入例であり、起動前に今回の対象へ置き換える。委譲元エージェントは各条件の証拠を確認して判定し、一般的な未確認範囲と必須条件の未達を区別する。
